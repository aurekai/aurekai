# Aurekai-owned sites and editorial presentation

Bonfÿre owns **generic compilers and native authoring/rendering contracts**. Aurekai owns its publication content, design system choices and deployment selection.

- [territory front-door content](content/territory-presentations.jsonl): per-site headlines, editorial direction, article/feed emphasis and refusal notes.
- [house visual roles and tokens](content/territory-houses.json): Aurekai's visual/editorial variations and design references.
- [route presentations](presentation/route-presentation.jsonl): Aurekai-specific page choices, many sourced from the Stitch design cohort.
- [Stitch presentation templates](presentation/presentation-template-stitch.jsonl): business-owned visual variations.
- [projection input](content/territory-presentation-surface.json) and [publication research](content/publication-observations-20261018.json): historical source identities and input material.

These have been copied with exact git blob identity from their former Bonfÿre paths; embedded references remain unchanged for lineage. Current CMS and binary readers are not assumed updated by the file move. A hosted route, authenticated edit workflow or public design parity needs separate exact production verification.
