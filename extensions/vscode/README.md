# Aurekai Workbench

VS Code and Open VSX extension for Aurekai manifest validation and CLI helpers.

## Commands

- `Aurekai: Run Deep Doctor`
- `Aurekai: Run Recipe`
- `Aurekai: Install (--user)`
- `Aurekai: Open Dashboard`
- `Aurekai: Inspect .akmodel`
- `Aurekai: Inspect Manifest`

## Formats

- `.akmodel` / `.bfmodel`
- `.aksae` / `.bfsae`
- `.akfpqx` / `.bffpqx`
- `aurekai.manifest.json`
